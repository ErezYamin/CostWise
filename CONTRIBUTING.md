# Contributing to CostWise

## Branch workflow
- Branch off `develop` for all new work
- Name your branch: `feature/<your-name>/<what-you're-building>`
- Open a PR into `develop` when your feature is ready
- At least one teammate must review before merging
- `main` is only updated when we have something demo-ready

## Commit message format
```
feat: short description of what you added
fix: short description of what you fixed
```

## Before opening a PR
- Make sure your code runs locally
- Resolve any merge conflicts with develop yourself
